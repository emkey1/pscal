# B0, B1 and B0-small on hosted models (OpenRouter twin), 2026-10-10 to 2026-10-12

The owner moved future boards to hosted inference. This is the same baseline as
`../b0_20261007/` (read its README first: same frozen compiler, binary sha256
`addfeb8d…acc9b66`, same guides, frozen task files, prompts, seeds, 3 repeats,
2 repair rounds) run on hosted copies of the panel models, so that later hosted
boards have a like-for-like baseline. **Pair hosted boards with this directory,
never with the local one:** the providers serve different weight formats.

`destinations.openrouter_20261010.json` is the configuration: one provider per
model, pinned with fallbacks off, so a result is one provider's weights.

Reading it:

- **The two larger qwen models match their local scores** (local repeat 0: 70
  and 68 of 73; hosted 70–72 and 68–72). Hosted and local are interchangeable
  for them.
- **Small guide against medium guide, qwen3.5-9b:** level on first attempt
  (61.6% against 62.1%). The small guide trades coded errors (14 against 40)
  for more empty first attempts (57 against 33) and more silent-wrong (13
  against 9). After repair it is 87.7% against 84.9% as run, and 68.0% against
  77.6% under the no-retry rule: the small guide's advantage after repair came
  entirely from rescuing empty first attempts.
- **qwen3.5-9b's empty first attempts** (15% with the medium guide, 26% with the
  small guide, 76% with the card on traps) are the reason its units ran for
  hours and the reason for the no-retry rule. Whether the provider cuts it off
  below the requested cap was not established; the model is due to be replaced
  in the panel.
- **Traps:** the two larger models are at 53% first attempt with the medium
  guide and 42–43% with the card; 16–23 of each 72 first attempts are
  silent-wrong, which is the class the traps exist to expose. Repair lifts
  qwen3.6-27b to 78–79%.
- **Between-repeat spread of first attempt on B0** (standard deviation of the
  per-repeat rate): 1.6 points for qwen3.6-27b, 2.9 for qwen3.6-35b, 2.1 for
  Bonsai, 6.5 for qwen3.5-9b. Plan 2.2 sizes B_G1's repeats from this.

## Incidents

Detail in `RUN_LOG.md`. None left an unmeasured case in the tables.

1. A pinned provider rate-limited qwen3.6-35b at the first request of its traps
   board, rejecting three units; they ran a day later.
2. qwen3.5-9b's traps units ran for up to 19 hours with re-run rounds.
3. A resumed unit was accepted with 3 of its 5 cases after the model check
   failed on the resume; found from its status line, re-run, and every unit of
   every board set audited for a full case count (this was the only one).
4. The no-retry rule arrived mid-set. It takes effect at a board boundary: B0,
   B1 and B0-small ran on the earlier harness, P0, S0 and the Python baseline
   run on the new one. `FX nr` makes the two comparable.

Cost: $25.77 of key usage when B0-small finished (B0 about $8.6, the traps
board about $4.6 per model).
