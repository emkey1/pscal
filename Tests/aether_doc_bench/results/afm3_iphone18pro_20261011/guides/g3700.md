# Aether guide

Aether is a small statically typed language. Answer with raw Aether source
only: no prose, no code fence, and never the expected output after the program.

## Every program has this shape

```aether
const LIMIT: Int = 3;

fn square(n: Int) -> Int {
    ret n * n;
}

fn main() -> Void {
    let total: Int = 0;
    loop i in 1..LIMIT + 1 {
        total = total + square(i);
        fx { println("square ", i, " = ", square(i)); }
    }
    fx { println("total = ", total); }
    ret;
}
```

```text
square 1 = 1
square 2 = 4
square 3 = 9
total = 14
```

- The top level holds only `use`, `const`, `type` and `fn`. Statements and
  `fx` go inside a function. The program runs `fn main() -> Void`, and `main`
  ends with `ret;`.
- The keyword is `ret`, never `return`: `ret n * n;` or `ret;`. It leaves the
  function at once; it never prints and never collects values.
- Each output line is one `println(...)` inside `fx { ... }`. Its arguments
  print with nothing between them, so spaces and punctuation go in the text:
  `println("step ", n, ": ", level);` prints `step 1: 7`. `print` adds no
  newline. Values asked for "on separate lines" get one `println` each.
- A range stops before its end: `1..4` is 1, 2, 3. For 1 to N inclusive write
  `1..N + 1`.
- Print exactly the lines the task asks for, with values the program computed.

## Not Python, JavaScript or Rust

Aether looks familiar but differs. Always write the left column:

| Write | Never write |
|---|---|
| `ret x;` and `ret;` | `return` |
| `fn add(a: Int, b: Int) -> Int { ... }` | `def`, `function`, `fn add(a, b)`, `fn f(n: Int): Int` |
| `loop i in 0..n { ... }`, `loop x in xs { ... }`, `loop k > 0 { ... }` | `for`, `while` |
| `x = x + 1;` | `x += 1`, `x++` |
| `Int`, `Real`, `Text`, `Bool`, `T[]` | `int`, `float`, `Float`, `String`, `str`, `List` |
| `let xs: Int[] = [];` then `xs = xs + [v];` | `xs.push(v)`, `xs.append(v)` |
| `length(xs)`, `length(s)` | `len(xs)`, `xs.length`, `xs.size()` |
| `const N: Int = 3;` (one number, text or bool) | a `const` array, object or file data |
| `fx { println("n = ", n); }` | printing outside `fx`, `"{}"` or `f"..."` |
| `use "file_name";` | `import`, `from`, `require` |
| `!done` | `not done` |
| `let v: Int = if c { 1 } else { 2 };` | `c ? 1 : 2`, `1 if c else 2`, `if c then 1` |
| `type Item { name: Text = ""; qty: Int = 0; }` (fields end with `;`) | `type X = ...`, `class`, `struct`, fields ending in `,` |

## Values and control flow

Types: `Int`, `Real`, `Text`, `Bool`, `Void`, arrays `T[]`, tuples, your own
`type`s. `let x: Int = 0;` declares a mutable local; declare a name once, then
assign with `x = x + 1;`. Annotate every array: `let xs: Int[] = [1, 2];`.

```aether
fn main() -> Void {
    let xs: Int[] = [4, 9];
    let k: Int = 3;
    let big: Int = 1_000_000;
    let ok: Bool = k > 2 && !(k == 7 || big < 5);
    let third: Int = if k == 0 { 0 } else { 10 div k };
    loop k > 0 { k = k - 1; }
    loop {
        k = k + 5;
        if k >= 12 { break; }
    }
    fx {
        loop i in 0..2 { println("i=", i); }
        loop x in xs { println("x=", x); }
        if ok && third == 3 {
            println("yes ", k);
        } else if third > 3 {
            println("more");
        } else {
            println("no");
        }
    }
    ret;
}
```

```text
i=0
i=1
x=4
x=9
yes 15
```

`loop k > 0 { }` is a while loop; bare `loop { }` runs until `break`;
`continue` skips ahead. `if` used as a value needs braces and an `else`.
Integer division is `a div b` and the remainder is `a mod b`; `a / b` gives a
`Real`. Boolean operators are `&&`, `||`, `!`.

## Functions, tuples, contracts

```aether
@pure
fn label(score: Int) -> Text {
    if score >= 50 { ret "pass"; }
    ret "fail";
}

@pre count > 0
@post result >= 0
fn average(total: Int, count: Int) -> Int {
    ret total div count;
}

@post result.0 <= result.1
fn lowHigh(a: Int, b: Int) -> (Int, Int) {
    if a <= b { ret (a, b); }
    ret (b, a);
}

fn fact(n: Int) -> Int {
    if n <= 1 { ret 1; }
    ret n * fact(n - 1);
}

fn main() -> Void {
    let (lo, hi) = lowHigh(8, 3);
    let t = lowHigh(7, 5);
    fx {
        println("label=", label(72));
        println("average=", average(9, 2));
        println("fact=", fact(5));
        println("lo=", lo);
        println("hi=", hi);
        println("first=", t.0);
    }
    ret;
}
```

```text
label=pass
average=4
fact=120
lo=3
hi=8
first=5
```

Every parameter is typed and every `fn` states `-> Type`. A tuple is returned
with `ret (a, b);` and taken apart with `let (x, y) = f();`, or bound and read
as `t.0`, `t.1`. `@pre` and `@post` go on their own lines above `fn`, without `;`;
`result` is the returned value (`result.0` for a tuple slot). A `@pure` function has no `fx` and calls only pure functions. There are
no lambdas and no `map`, `filter`, `sort` or `join`: write a `loop`.

## Types and methods

```aether
type Counter {
    label: Text = "count";
    value: Int = 0;

    fn add(by: Int) -> Int {
        self.value = self.value + by;
        ret self.value;
    }
}

fn double(self: Counter) -> Int {
    ret self.value * 2;
}

fn main() -> Void {
    let c: Counter = new Counter { label: "hits", value: 1 };
    let d: Counter = new Counter();
    c.add(2);
    fx {
        println(c.label, "=", c.value);
        println("twice=", c.double());
        println(d.label, "=", d.value);
    }
    ret;
}
```

```text
hits=3
twice=6
count=0
```

Fields have literal defaults and end with `;`. `new T()` keeps the defaults;
`new T { field: value }` sets some. A method inside the `type` uses
`self.field` and declares no `self` parameter. An extension method is a
top-level `fn` whose first parameter is `self: T`; both are called `c.name()`.

## Arrays and text

```aether
fn main() -> Void {
    let xs: Int[] = [3, 8, 5];
    xs = xs + [6];
    xs[0] = 7;
    let sum: Int = 0;
    let best: Int = xs[0];
    loop i in 0..length(xs) {
        sum = sum + xs[i];
        if xs[i] > best { best = xs[i]; }
    }
    let grid: Int[][] = [[1, 2], [3, 4]];
    let s: Text = "hello world";
    let words: Text[] = split(s, " ");
    let n: Int = parse_int("41") + 1;
    fx {
        println("sum=", sum);
        println("best=", best);
        println("count=", length(xs));
        println(xs[1..3][0], " ", grid[1][0], " ", s[0], " ", s[0..5]);
        println(words[1], " ", length(s), " ", pos("o", s), " ", s == "hi");
        println("n=" + int_to_text(n), " ", copy(s, 6, 3), trim("  !  "));
    }
    ret;
}
```

```text
sum=26
best=8
count=4
8 3 h hello
world 11 4 false
n=42 wor!
```

Indexes start at 0. An array is a `let` inside a function, never a `const`.
Append with `xs = xs + [v];`. Start a minimum or maximum
from `xs[0]`. `println` cannot print a whole array; loop over it. `s[i]` is a
one-character `Text`, `copy(s, start, count)` a substring, `pos(needle, s)` the
first index or `-1`. `+` joins `Text`; `int_to_text(n)` converts a number.

## Real numbers

```aether
const RATE: Real = 0.175;

fn main() -> Void {
    let done: Int = 3;
    let all: Int = 8;
    let share: Real = done * 100.0 / all;
    let tax: Real = 40.0 * RATE;
    fx {
        println("share=", share:0:2);
        println("tax=", tax:0:1, " raw=", tax);
        println("text=" + formatfloat(share, 1));
    }
    ret;
}
```

```text
share=37.50
tax=7.0 raw=7.000000
text=37.5
```

Inside `println`, `value:0:2` prints a `Real` with 2 decimals; without it a
`Real` prints 6. `formatfloat(r, digits)` gives the same as `Text`. Multiply by
a `Real` (`100.0`) before dividing two `Int`s.

## Modules

A module is a file of exported constants and functions. Import it by file name
on the first line, then use the exported names directly:

```aether
use "score_utils";

fn main() -> Void {
    fx {
        println("base = ", BaseScore);
        println("clamped = ", clampScore(140));
    }
    ret;
}
```

```text
base = 50
clamped = 100
```

## Reading JSON (TOON)

`trip.json` holds `{"city":"Oslo","open":true,"stops":[{"id":7,"tags":["a","b"]},{"id":9}]}`.

```aether
fn main() -> Void {
    if !has_toon() {
        fx { println("toon unavailable"); }
        ret;
    }
    fx {
        let doc: ToonDoc = toon_parse_file("trip.json");
        let root: ToonNode = toon_root(doc);
        let city: Text = toon_get_text_or(root, "city", "?");
        let open: Bool = toon_get_bool_or(root, "open", false);
        println("city ", city);
        println("open ", open);
        let stops: ToonNode = toon_key(root, "stops");
        let total: Int = 0;
        loop i in 0..toon_len(stops) {
            let stop: ToonNode = toon_at(stops, i);
            let id: Int = toon_get_int_or(stop, "id", 0);
            let tags: Int = 0;
            if toon_has_key(stop, "tags") {
                tags = toon_len(toon_key(stop, "tags"));
            }
            total = total + tags;
            println("stop ", i, " id ", id, " tags ", tags);
        }
        println("total tags = ", total);
        toon_close(doc);
    }
    ret;
}
```

```text
city Oslo
open true
stop 0 id 7 tags 2
stop 1 id 9 tags 0
total tags = 2
```

- Types are `ToonDoc` (the parsed document) and `ToonNode` (any value in it).
  There is no JSON object type, no `data.name`, no `data["name"]`.
- `toon_parse_file("f.json")` must be inside `fx`. For JSON already in a
  `Text`: `let doc: ToonDoc = toon_parse("{\"n\":1}");`, which needs no `fx`.
- Read a field with `toon_get_text_or(node, "key", fallback)`, or
  `toon_get_int_or`, `toon_get_bool_or`, `toon_get_real_or`.
- `toon_key(node, "key")` gives a nested object or array; check
  `toon_has_key(node, "key")` first when it may be missing. An array has
  `toon_len(arr)` items; `toon_at(arr, i)` is item `i`.
- An item's kind: `toon_is_int(n)`, `toon_is_real(n)`, `toon_is_text(n)`,
  `toon_is_bool(n)`.
- Finish with `toon_close(doc);`.

## Memory streams

```aether
fn main() -> Void {
    let ms: MStream = mstreamfromstring("abc def");
    let body: Text = mstreambuffer(ms);
    fx { println("body = ", body, ", len = ", length(body)); }
    mstreamfree(ms);
    ret;
}
```

```text
body = abc def, len = 7
```

## Diagnostics

| Code | Cause | Fix |
|---|---|---|
| FX-001 | `println` or a file call outside `fx` | wrap it in `fx { ... }` |
| SYN-001 | `return`, `import`, `for`, `+=`, code at top level | `ret`, `use "name";`, `loop`, `x = x + 1;`, move it into `fn main` |
| SCOPE-001 | unknown name or invented function | declare it, or use a function shown in this guide |
| TYPE-001 | type cannot be inferred | annotate: `let xs: Int[] = [];` |
| TYPE-002 | unknown type such as `Integer` or `String` | `Int`, `Real`, `Text`, `Bool` |
| NAME-001 | local declared twice | assign without `let` |
| TUP-001 | `f().0` | bind first: `let t = f();` |
| ARR-003 | index out of range | loop `0..length(xs)` |

## Before you answer, check

1. There is a `fn main() -> Void { ... ret; }` and nothing but `use`, `const`,
   `type` and `fn` at the top level.
2. No `return`, `import`, `for`, `while`, `+=`, `String` or `len` anywhere.
3. Every `println` is inside `fx { ... }`, one per output line, with the exact
   text, spaces and punctuation the task shows. Lines the task lists separately
   are separate `println` calls.
4. Ranges stop before their end.
5. The answer is the program only.
