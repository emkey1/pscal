# devstral-small-2 on its MLX 4-bit weights: B0, B1, P0, Python baseline, 2026-10-11/12

A companion to `../b0_20261007/` (read its README first; same frozen compiler,
guides, frozen task files, prompts, seeds and settings). It exists because the
serving host resolved the model name `mistralai/devstral-small-2-2512` to a
different weight file part-way through the baseline: the B0 units of 2026-10-07
and the morning of 2026-10-11 ran on the Q8_0 GGUF, later loads got the MLX
4-bit build. Rather than mix weights inside one model's boards, every unit that
ran on 4-bit was moved here and the set was completed on 4-bit, with a guard
checking the loaded file every three minutes (it saw the 4-bit safetensors,
14,120,998,772 bytes, at every check).

So this is the one complete, self-consistent devstral set: 36 units, 744 cases,
3 repeats, no rejected or parked units. `summary.md`, `summary.json` and
`MANIFEST.json` are generated by
`../b0_20261007/summarize_b0.py --dir <this directory>`.

Reading it:

- **4-bit against Q8_0:** level. Repeat 0 totals 47 against 46 of 73; 4-bit is
  three tasks lower on the simple suite and two higher on hard_v2, and within a
  task after repair on every suite.
- **Medium guide against card:** the card costs this model about nine tasks of
  35 on the simple suite and five of 19 on cs, and most of the traps board
  (12.5% against 43.1% first attempt).
- **Aether against Python:** with the medium guide devstral is ahead in Aether on
  the simple and hard suites (28 against 22, 5 against 1) and behind on cs (13
  against 18). Eleven simple tasks and the hard_v2 suite use Aether-only features
  (module files, the JSON calls, contracts) that Python cannot satisfy as
  posed, so the cs suite is the clean language comparison: plain algorithm
  tasks, where Aether costs this model about five tasks of 19.
- Traps: 20 and 28 of the 72 first attempts per guide are silent-wrong, the
  class the traps exist to expose.

The model shared its host with other traffic during this set, so wall-clock
times are not comparable with other units. Nothing else differs.
